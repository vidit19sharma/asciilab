# asciilab

Privacy-first image & text to ASCII / ANSI / braille / block art converter. Runs entirely in your browser — nothing is uploaded.

> Status: in development. See the [design spec](docs/superpowers/specs/2026-10-28-asciilab-design.md).

## Packages

| Package | Description |
|---|---|
| `apps/web` | Web app (Vite + React) |
| `packages/engine` | `@asciilab/engine` — zero-dependency TypeScript rendering engine |
| `packages/cli` | `asciilab` — command-line interface |
